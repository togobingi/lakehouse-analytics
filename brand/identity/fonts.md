# Lakehouse Analytics: fonts

- **Wordmark and image headlines:** Avenir Next. "Lakehouse" in Demi Bold, "Analytics"
  in Medium. Ships with macOS, so the PNGs render the same on Robin's and Tobi's Macs.
- **Body text in images and diagrams:** Avenir Next Regular.
- **Fallback (non-Mac or web):** [Nunito Sans](https://fonts.google.com/specimen/Nunito+Sans)
  (open license), which has a similar geometric shape.
- **Posts themselves:** use Substack's built-in theme font. Do not fight the platform.

The SVG sources reference the font by name, so open them on a Mac or use the PNGs.
