The problem

Parquet v1 keeps min / max only in the file footer, one set per row group.

A filter on one day still has to read and decompress every page of that column chunk.

Delta's file stats already skip whole files. This is about the pages inside a file.

What v2 adds

1Page headers with stats and indexes, so a reader can skip pages inside a file
2Newer encodings for integer and string columns
3INT64 timestamps instead of INT96

The footer stays: it still holds the schema and row groups.
